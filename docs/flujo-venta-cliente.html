Nota: En cualquier momento que el asistente no pueda resolver algo, se transfiere al usuario de la plataforma y se le notifica por WhatsApp para que atienda al cliente.

1. Saludo y deteccion

  • El cliente escribe al WhatsApp
  • El asistente saluda y detecta que necesita el cliente
  • Si el cliente quiere comprar algo, sigue el flujo de venta
  • Si quiere otra cosa (credito, servicio, etc.) se transfiere a HITL HITL

2. Identificacion del producto y precio

  • El asistente busca en los equipos y productos que le hemos manejado al cliente
  • Si el cliente tiene 3 o mas productos similares, se le ofrece el juego completo
  • Se le ofrece los productos que ya conocemos del cliente
  • Si el producto no existe en nuestro sistema, se notifica al usuario de la plataforma para que nos de el precio y poder continuar
  • Se le da el precio al cliente (con IVA incluido)
  • Se le pregunta si pasa por el producto o se le envia
  • Si es fuera de Quetzaltenango se le cobra envio (transporte urbano o Guatex)
  • Se le da el total final al cliente
Si el cliente acepta el precio, sigue al cobro. Si negocia, el asistente intenta manejarlo si ya conoce al cliente, si no se transfiere a HITL. Si rechaza, se registra y se notifica al usuario de la plataforma.

3. Negociacion (si aplica)

  • Si es un cliente nuevo que nunca ha negociado, se transfiere a HITL directamente HITL
  • Si es un cliente conocido, el asistente usa el historial de negociaciones anteriores para saber como maneja el cliente y seguir el juego
  • Si se llega a un acuerdo, sigue el flujo
  • Si no se llega a acuerdo, se registra como venta perdida y se notifica al usuario de la plataforma para intentar recuperarla

4. Facturacion opcional

El cliente puede pedir factura en cualquier momento del proceso.

  • Se le pide el NIT al cliente (si no lo tenemos)
  • Se le pide al usuario de la plataforma que mande una foto del producto
  • La foto se manda al grupo tecnico para despacho
  • Se envia la solicitud de factura a ventas/contadora con: NIT, que se esta vendiendo (lo mas especifico posible), precio y total
  • Cuando la contadora devuelve la factura, se la mandamos al cliente
Las solicitudes de factura se mandan una por una. Se envia una, se espera la respuesta, y luego se envia la siguiente. Asi no se satura a la contadora.

5. Cobro y verificacion de pago

  • Se le pide al cliente que haga el deposito o transferencia
  • Si el cliente quiere pagar con visa link, se transfiere a HITL porque tiene otro costo HITL
  • Si el cliente no envia el comprobante, se le mandan recordatorios:
Recordatorios (si no se recibe comprobante):
Se envian si ya pasaron 2 horas del ultimo contacto.
1er recordatorio: 3pm   |   2do: 5pm   |   3ro: 9am del dia siguiente
Si despues de los 3 recordatorios no hay respuesta, se notifica al usuario de la plataforma y se registra como venta perdida.
  • El cliente envia el comprobante
  • Se le envia el comprobante al usuario de la plataforma por WhatsApp para que lo revise
  • Usted puede aceptar o mandar correcciones (si corrige, se modifica y se le vuelve a enviar para confirmacion)
  • Se envia al grupo de verificacion
  • Se espera que la supervisora confirme con la palabra "confirmado" junto con el recibo

6. Despacho

  • Si no se paso por facturacion antes (donde ya se mando la foto al grupo tecnico), se hace ahora
  • Se le pide al usuario de la plataforma la foto del producto, se manda al grupo tecnico para despachar

7. Despedida

  • Se le envia un mensaje de despedida al cliente
  • Si el cliente sigue escribiendo cosas como "gracias" o "ok", se ignora
  • Si el cliente escribe algo nuevo, se inicia una nueva conversacion

Notificaciones

Usted no necesita estar pendiente todo el tiempo. El asistente le notifica por WhatsApp cada vez que necesita su atencion:

  • • Cuando un cliente necesita HITL
  • • Cuando un cliente nuevo inicia una conversacion
  • • Cuando necesitamos un precio de un producto
  • • Cuando necesitamos verificar un pago
  • • Cuando se pierde una venta
